# Latest Example Configs

This directory contains six self-contained example configs for global MC searches around two cage conformers:

- `CC3_3F`
- `CC19_3F`

and three anion systems:

- `Br12`
- `OTf12`
- `SO4_6`

The referenced input structures are all in `example_inputs/`.

## Configs

- `cc3_3f_br12_global.yaml`
- `cc3_3f_otf12_global.yaml`
- `cc3_3f_so4_6_global.yaml`
- `cc19_3f_br12_global.yaml`
- `cc19_3f_otf12_global.yaml`
- `cc19_3f_so4_6_global.yaml`
